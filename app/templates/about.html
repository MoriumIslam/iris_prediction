About This Project

Learn about the machine learning model and dataset

🎯 Project Overview

The Iris Species Predictor is a machine learning web application that classifies iris flowers into one of three species based on their physical measurements. This project demonstrates a complete end-to-end machine learning pipeline from training to production deployment.

📊 The Iris Dataset

The Iris dataset is one of the most famous datasets in machine learning and statistics. It was collected by Ronald Fisher in 1936 and contains measurements of iris flowers from three different species:

  • Iris Setosa: A small species with distinctive characteristics
  • Iris Versicolor: A medium-sized species with intermediate measurements
  • Iris Virginica: The largest species with longer petals

Each sample includes four measurements (in centimeters): sepal length, sepal width, petal length, and petal width.

🤖 Machine Learning Model

This application uses a pre-trained machine learning model to make predictions. The model was trained on the complete Iris dataset using a supervised classification algorithm. It learns the relationship between the flower measurements and their species.

Model Accuracy: High accuracy on the test set ensures reliable predictions for new iris flower measurements.

🛠️ Technology Stack

  • Backend: Python with Flask web framework
  • Frontend: HTML5, CSS3, and Vanilla JavaScript
  • Model: Scikit-learn trained classifier (pickle format)
  • Deployment: Production-ready for cloud platforms like Render

🚀 How It Works

  1. You enter the measurements of an iris flower
  2. The app sends the data to the backend API
  3. The pre-trained model analyzes the measurements
  4. The model predicts the most likely iris species
  5. Results are displayed with confidence score and species information

📚 Why Iris?

The Iris dataset has become a classic benchmark in machine learning for several reasons:

  • It's small enough to understand completely
  • It's large enough to demonstrate real machine learning techniques
  • It has clear, measurable features
  • It's balanced across the three classes
  • It's publicly available and well-documented
